# Calorie Tracker

This repository is a training project created to practice Django and React development, and also Tensoflow neural networks training. It is not intended to provide full funcionality. More instructions on the other Readme's

---------

## Launch

To run the application with Docker, execute the following command from the project directory:

```bash
docker compose up -d
```

Once the containers are running, open the application at:

`
localhost:3000
`

Where the app is located.

----------

## Backend Admin Dashboard

The Django admin dashboard is available at:

`
localhost:8080
`

You can use it to manage application data.
