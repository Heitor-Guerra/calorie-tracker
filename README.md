---------





## Launch

To run the application with Docker, execute the following command from the project directory:

```bash
docker compose up -d
```

Once the containers are running, open the application at:

`
localhost:3000
`

Where the app is located.

----------

## Backend Admin Dashboard

The Django admin dashboard is available at:

`
localhost:8080
`

You can use it to manage application data.
